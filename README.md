# DeepSeekIDE

IDE-ускоритель для DeepSeek **без API-ключей**: агент работает через обычный веб-чат
[chat.deepseek.com](https://chat.deepseek.com), а среда разработки открывается прямо
в вашем браузере. Бесплатно: используется ваш существующий логин DeepSeek (через Google и т.п.).

## Как это устроено

```
deepseekide.exe  = локальный HTTP-сервер (127.0.0.1, порт выбирается автоматически)
   ├─ /           → фронтенд IDE:      assets/web (HTML/CSS/JS + Monaco Editor)
   └─ /api/...     → проект, файлы, снапшоты, журнал, мост к агенту
Отдельно запускается Chrome/Edge с отладочным портом (CDP):
   вкладка chat.deepseek.com — туда IDE отправляет задачи и читает ответы.
```

Никакого WebView2/ImGui — только ваш собственный браузер. Поэтому работает везде,
где есть Chrome или Edge.

## Сборка (Windows)

1. Visual Studio 2022+ (компонент *Desktop development with C++*), CMake 3.24+ в PATH.
2. Дважды щёлкните **`build-windows.bat`**. Получите `deepseekide.exe` в корне папки.
3. Запустите `deepseekide.exe` → в браузере откроется IDE.

## Сборка вручную (любая ОС)

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j          # deepseekide + deepseekide_tests
```

## DeepSeek Extended — чистое расширение (звезда шоу)

**Никакого сервера и .exe.** Всё — в браузере: агент читает/пишет/ищет по
папке вашего проекта напрямую через File System Access API, снапшоты лежат в
IndexedDB. Установка один раз, три клика:

1. Скачайте репозиторий (или папку `extension/` из артефакта CI).
2. Откройте `chrome://extensions` (или `edge://extensions`) → включите
   **«Режим разработчика»** → **«Загрузить распакованное расширение»** →
   выберите папку `extension/`.
3. Откройте `chat.deepseek.com` — расширение **невидимое**: в ряду нативных
   тумблеров сайта («Глубокое мышление», «Умный поиск») появляется родная
   пилюля **«🛩 Авто-пилот»**.
4. Включите её — при первом включении откроется выбор **папки проекта**
   (запоминается; после перезапуска браузера — один клик подтверждения).
   Зелёный огонёк на пилюле = автопилот вооружён.
5. **Дальше просто общайтесь.** Системный промпт с деревом проекта сам
   незаметно подмешивается к первому сообщению, дальше — короткие
   напоминания протокола; в чате вы видите только СВОЙ текст. Когда модель
   просит файлы (NEED FILE/NEED SEARCH), они улетают скрыто, а вы видите
   лишь аккуратный чип «📖 Прочитано: "main.cpp"». Правки применяются
   мгновенно, статус — микро-тостами в углу.

Единственное ограничение песочницы браузера: **терминала нет** — команды
сборки/тестов расширение не выполняет (модель поведает их текстом). Когда
нужен и терминал — есть C++-режим ниже.

## Использование (C++-режим, с терминалом)

### Режим 1 — расширение-автопилот, сопровождаемое DeepSeekIDE.exe

Работа прямо на `chat.deepseek.com`, без отдельного робо-браузера (CDP):

1. **Откройте проект** (слева «Открыть…»).
2. В панели чата нажмите **«⧉ Установить и открыть браузер»** — IDE запишет
   распакованное расширение в `%APPDATA%/DeepSeekIDE/extension` и запустит
   Chrome/Edge с флагом `--load-extension` (профиль отдельный, логин один раз).
3. На странице DeepSeek в правом нижнем углу появится стеклянная таблетка
   **«DeepSeekIDE · автопилот»**: статус, «⟡ Прайм» (отправить системный
   промпт в чат), «⏸/▶» (пауза), «IDE ↗».
4. Дальше вы просто **общаетесь с DeepSeek как обычно**. Расширение само
   замечает готовый ответ, отправляет его в IDE; ops применяются мгновенно,
   отчёты и запрошенные файлы (NEED FILE/NEED SEARCH) автоматически уходят
   модели следующим сообщением.
5. Если браузер сам не запустился (редко) — `chrome://extensions` → режим
   разработчика → «Загрузить распакованное расширение» → выберите папку
   из журнала IDE (`%APPDATA%/DeepSeekIDE/extension`).

Всё, что расширение делает и видит, пишется в журнал IDE (эндпойнт
`/api/ext/log`) — при проблемах этот журнал достаточно прислать нам.

### Режим 2 — встроенная веб-морда (запасной)

1. **Откройте проект** (слева «Открыть…», укажите папку).
2. **«Подключить чат»** — запустится Chrome/Edge с вкладкой `chat.deepseek.com`.
   Войдите в свой аккаунт DeepSeek **один раз** (сессия сохраняется в отдельном
   профиле браузера `%APPDATA%/DeepSeekIDE/browser-profile`).
3. Сформулируйте **задачу** справа → Enter/Ctrl+Enter/«Отправить задачу».
   Индикатор покажет: «отправлено» → «печатает…» → «ответ получен».
4. Ответ агента разбирается автоматически: операции с файлами (`write_file`,
   `edit_file`, `insert_lines`, `replace_lines`, `make_dir`, `delete_path`,
   `copy_file`, `move_file`, …) **применяются сразу, без подтверждения** —
   отчёт об этом приходит модели следующим сообщением и пишется в журнал.
   Чекбоксы «Применить» в панели остались как ручной запасной путь.
5. Каждое применение создаёт **снапшот** — в любой момент можно
   **«откатить к этому»** из панели «Снапшоты».
6. **Самообслуживание агента.** Если модели нужен файл, она сама пишет
   `NEED FILE: <путь>` отдельной строкой — IDE присылает содержимое
   с пронумерованными строками. `NEED SEARCH: <текст>` — поиск по проекту
   с ответом `файл:строка: текст`. Делать ничего не нужно.
7. **Терминал агенту.** Тумблер в шапке («терминал агенту») разрешает
   модели `run_command`: сборка, тесты, установка пакетов. Вывод команд
   автоматически возвращается модели следующим сообщением — она итерирует
   «написал → собрал → починил» без вашего участия. По умолчанию выключено;
   настройка хранится в `settings.json` (`allow_shell`, `shell_timeout`).

## Безопасность

- Сервер слушает только `127.0.0.1`, все `/api/*` закрыты случайным токеном
  (передаётся в URL при автостарте и хранится в sessionStorage вкладки).
- Путь в API-файлах проверяется: нельзя выйти за пределы проекта.
- Браузера агента — обычный Chrome/Edge, в который вы сами вошли; мы только
  нажимаем кнопку «отправить» и читаем последний ответ.
- `run_command` исполняется только внутри корня проекта и только при включённом
  тумблере «терминал агенту»; таймаут команды ограничен (по умолч. 60 с,
  максимум 600 с). Системный промпт дополнительно запрещает модели
  разрушительные команды и работу вне проекта.

## Положение файлов

| Что             | Где                                                  |
|-----------------|------------------------------------------------------|
| Серверный бэкенд | `src/server/IdeServer.*`, `src/main.cpp`             |
| Агент (CDP)      | `src/chat/ChatDriver.*`, `src/cdp/CdpClient.*`, `src/ws/WsClient.*` |
| Инструменты      | `src/ai/ToolRegistry.*`, `src/ai/OpsParser.*`        |
| Ядро             | `src/core/ProjectManager.*`, `src/core/SnapshotManager.*` |
| HTTP-клиент      | `src/net/HttpClient.*` (на всемогущем cpp-httplib)   |
| Фронтенд         | `assets/web/` (index.html, app.css, app.js)          |
| Юнит-тесты       | `src/tests/selftest.cpp` → `deepseekide_tests`       |
